# EDA 与图件方案模板（data-visualization 深化材料）

按需加载。本文给出四项内容：EDA 报告结构、预注册问题写法、vizgap 清单与图件卡片。

## 1. EDA 复算脚本头部（预注册问题）

```r
# _eda_<主题>_<yyMMdd>.R —— <主题> EDA 复算（只读；R 4.6.1）
# 预注册问题：
#   Q1: <分布与离群：主量分布如何？离群单元哪些？剔除后份额变化多少？>
#   Q2: <集中度：Top 单元占比？负单元占比与来源？>
#   Q3: <一致性：与上游表的总量对账（840,046 vs 840,438 类）？>
#   Q4: <关系：两个视角的秩相关？>
#   ...
# 数据：output/<表模式>.xlsx（<sheet>）——全部只读
# 输出：insight/<主题>_<yyMMdd>.md（结论 + 每个数可复算到源表）

source("R/_common_proc.R")
# ...逐 Q 实现，每个 Q 打印"问题 → 数值 → 判读"
```

要点三条。Q 先写后算，防止事后编故事。每个打印值都能反向追溯到源表 sheet。发现数据质量问题要**单列一节**，不改数。

## 2. EDA 报告结构

EDA 报告按以下结构写。

```markdown
# <主题> EDA（<yyMMdd>）

## 结论（先说答案）
- <每条 Q 一句话结论，带数值。>

## 数据质量发现（若有）
- <异常/缺口/口径疑点，注明影响与建议处置；不静默修改。>

## 可视化方案
- **V1 <名称>**：<面板设计一句话>；数据=<output 表/sheet>；命名=figN_<名称>。
- **V2**：...

## 可视化缺口清单
- **G1**：<现有图没覆盖的关键信息>；
- **G2**：...

## 升级项
- **A1**：<已有图待改进点>。

## 复算
- 脚本：`insight/_eda_<主题>_<yyMMdd>.R`；关键数：<表·sheet·单元 → 值> 清单。
```

## 3. 图件卡片（整套图方案的登记格式）

每张图在 `pics/README.md` 清单里占一行：

| 图 | 脚本 | 依据 | 意图一句话 | 数据源 | 代次/QA |
|---|---|---|---|---|---|
| fig1 | fig1_burden_map.R | V1 | 全球负担双面板：绝对 vs 人均 | by_receptor + socio_econ | 260906/双QA过 |
| SI_S8 | SI_Fig_S8_*.R | G6 | 口径敏感性面板 | qc/多表 | 260906/结构过·视觉NOT AUDITABLE |

SI 图的典型分工如下。准备与对齐：覆盖连接表、空间模式覆盖率。各 step 细节：排放、浓度、负担、公平性。方法学：敏感性、非线性加和性。主图不塞细节。

## 4. 图面诚实注记清单（发图前逐项过；说明写进 figure caption）

图面只留读图必需的标记，如轴标签与单位、图例、比例尺、显著性符号。括号解释与图底「注：…」行不进图。

- [ ] 剔除的单元（离群如 Haiti、微型领土）→ caption “已剔除 X（原因），份额变化 ≤Y”
- [ ] 截断（色阶 >N 封顶、占比 >1 截断）→ caption 说明
- [ ] 只保留正单元的视图 → caption “负单元 N 个（占 M%）未显示，见 qc sheet”
- [ ] Σ≠ 口径（8 品类加总 ≠ All products）→ caption 注 “Σ8 ≠ All（≈Z%）”
- [ ] 单位与色阶变换（√/log10/分步）→ 轴或图例标注
- [ ] 加权口径声明（“人口加权已内嵌于源值”类，防读者误加）→ caption
- [ ] 数据代次日期 → caption 或文件名体现，不写进图内角落

## 5. 整代重跑清单（口径变更时）

口径变更后，按以下五步整代重跑。

1. 列出全部现行 figN/SI_Fig 脚本。逐个重跑，要求 exit 0 且无新警告。
2. 关键打印值要能复现 insight/审计基准。每图挑 1 至 3 个统计量。
3. 新代 PNG 齐备后，旧代图件整批删除，图脚本归档到根 `deprecated/pics/`；handoff 记代次切换与删除原因。
4. 某图数值受口径影响而变，则回填更正该图的 insight 结论，并注明。
5. 更新 `pics/README.md` 清单的代次列。handoff 留痕。
